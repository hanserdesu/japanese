WCP 日语词库（猫条版）一键安装包

当前版本：v1.1.6

使用方法：
1. 先关闭万词破。
2. 双击最外层的“01_双击运行我.cmd”，无需进入 support 文件夹。
3. 安装完成后重新启动游戏，词书会自动进入一个自定义词书槽。

安装器会自动搜索 Steam 的所有游戏库，不要求游戏安装在固定盘符或固定目录。
它会备份 MyBook.es3、SaveFile.es3 和已有插件，不会修改官方英语词书内容。

说明：
- 本包包含与作者实机一致的 BepInEx 5 运行环境、词书、核心插件和官方更新后的日语数据库自动修复资源。
- 安装器会从 GitHub Release 下载并校验约 2.3GB 的单词/例句音频，安装完成后的效果与作者本机实机包一致。
- 安装窗口会一直保持并显示时间戳进度；成功或失败后都会停留，请点击右上角 X 关闭窗口，按 Enter 不会关闭安装窗口。
- 下载音频需要稳定网络和至少 3GB 可用空间；音频下载失败时安装器会报错，修复网络后重新运行即可。
- 新用户不需要另装 BepInEx；安装器会自动安装随包提供的运行环境。已有 BepInEx 的用户会保留现有核心，只补齐缺失的启动文件。
- 如果四个自定义词书槽都已被占用，安装器会让你选择要替换的槽位；替换前会自动备份原 MyBook.es3。
- 启动器会优先使用系统 Windows PowerShell，找不到时自动切换到 PowerShell 7；两者都不满足要求时会显示兼容性提示且不会闪退。
- 启动器会先创建一个持续保留的 CMD 会话；无论安装成功、失败或运行环境不兼容，按 Enter 都不会关闭窗口。若需要排查，可把根目录生成的“installer-startup.log”发给维护者。
- 下载音频时会显示实时百分比、已下载容量和下载速度。
- v1.1.5 修复了部分电脑 Steam 注册表残留旧盘符（例如 E 盘已不存在）导致安装器直接失败的问题；无效盘符会自动跳过并继续搜索其他 Steam 库。
- v1.1.6 修复了上次安装失败后遗留临时解压目录导致再次安装失败的问题；每次安装使用独立临时目录，旧目录清理失败也不会阻断安装，并修复部分 Windows cmd.exe 的入口乱码提示。
